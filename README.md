# Coursera HTML5 Sample Project

This repository contains a sample front-end project created for a Coursera course on HTML5. It demonstrates a modern web development setup with a focus on user data collection, decorative UI/UX, and placeholder unit tests.

## Project Structure

The project is organized into the following files:

*   **`index.html`**: The main HTML file containing the structure of the user data collection form. It includes input fields for the user's name and email.

*   **`style.css`**: The stylesheet responsible for the decorative and responsive design of the UI. It uses custom fonts, modern colors, and box shadows to create an engaging user experience.

*   **`script.js`**: The JavaScript file that handles form submission. It prevents the default form action, captures the user's input, and logs it to the console as a placeholder for future database interaction.

*   **`tests/unit.js`**: A file containing placeholder unit tests. It demonstrates how one might write tests for form validation and data processing logic to ensure reliability and handle edge cases.

## Features

*   **User Data Form**: A simple and elegant form to collect user information.
*   **Decorative UI/UX**: A visually appealing interface with a focus on clean design and responsiveness.
*   **Form Submission Handling**: JavaScript-powered form submission that logs data to the console without a page reload.
*   **Unit Test Placeholders**: A clear structure for writing unit tests to ensure code quality.

## How to Run

To run this project, simply clone the repository and open the `index.html` file in your web browser.

```sh
git clone <repository-url>
cd courserahtml5sample
```
