# Coursera HTML5 Sample Project

This repository is intended to host a sample project for a Coursera course on HTML5. The project demonstrates the use of various HTML5 features and best practices.

## Contents

The project will include the following:

*   **index.html:** The main page of the sample application.
*   **css/style.css:** The stylesheet for the application.
*   **js/main.js:** The main JavaScript file for the application.

## Usage

To use this project, simply clone the repository and open the `index.html` file in your web browser.

```bash
git clone https://github.com/your-username/courserahtml5sample.git
cd courserahtml5sample
```
